# 🕵️ Telegram Spy Game Bot

Бот для игры в "Шпиона" в Telegram с поддержкой до 10 игроков!

## 🎮 Возможности

- ✅ Создание игровых комнат с уникальными кодами
- ✅ Настройка количества шпионов (1-3)
- ✅ 10 категорий слов (150+ слов)
- ✅ Поддержка до 10 игроков в комнате
- ✅ Красивый интерфейс с эмодзи
- ✅ Автоматическое распределение ролей
- ✅ Приватные сообщения с ролями

## 📂 Категории

- 🌍 Страны (110 стран)
- 🦸 Герои Marvel (100+ героев)
- 🦇 Герои DC (100+ героев)
- 🍕 Еда
- 🐾 Животные
- 🎬 Фильмы
- 🏙️ Города
- ⚽️ Спорт
- 🎵 Музыкальные инструменты
- 👔 Профессии

## 🚀 Установка на Railway

### Шаг 1: Создайте бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте /newbot
3. Следуйте инструкциям
4. Скопируйте токен бота

### Шаг 2: Деплой на Railway

1. Зарегистрируйтесь на [Railway.app](https://railway.app)
2. Нажмите "New Project" → "Deploy from GitHub repo"
3. Выберите ваш репозиторий
4. Добавьте переменную окружения:
   - BOT_TOKEN = ваш токен от BotFather

### Шаг 3: Запуск

Railway автоматически:
- Установит зависимости из requirements.txt
- Запустит бота через Procfile
- Перезапустит при ошибках

## 🎯 Как играть

1. Отправьте /start боту
2. Нажмите "Создать комнату"
3. Настройте количество шпионов и категорию
4. Поделитесь кодом комнаты с друзьями
5. Когда все присоединятся, начните игру
6. Бот отправит каждому роль в личные сообщения
7. Обсуждайте слово и вычисляйте шпиона!

## 📝 Правила

- Мирные жители получают общее слово
- Шпионы знают только категорию
- Описывайте слово намёками, не называя его
- Шпионы должны понять слово и остаться незамеченными
- Мирные жители должны найти шпионов
